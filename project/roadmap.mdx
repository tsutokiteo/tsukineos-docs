# 路线图

## 已完成

- Linux 6.6 LTS 底座
- 持久化存储
- 包管理工具（`tknpkg`）
- 网络层重构（`net`）
- 自研工具链：`taskmgr` / `net` / `ping` / `iwr` / `tknpkg` / `tknpkkj`
- ARM64 移植完成（Redmi Pad SE 验证）
- Infdev-0.2.4 双架构镜像发布

- x86_64 实体机 UEFI/BIOS 引导与驱动加载收尾（Infdev-0.2.4 后续小版本）

## 计划中

- **正式版 2.0.0** — 集成音乐创作工具
