# 路线图

## 已完成
- Linux 6.6 LTS 底座
- 命令行工具链（tsukine_top / net / ping / iwr）
- 包管理 tknpkg
- 持久化存储、网络栈重构
- ARM64 移植、IMG 镜像
- Indev-0.1.1 x86_64 实机启动

## 进行中
- x86_64 实体机启动适配
- UEFI 引导支持
- ARM64 外设完善

## 下一阶段（Alpha）
- 图形外壳（GUI）雏形
- 音频链路（PipeWire/JACK 类）接入命令行底座
- 安装器前期设计
