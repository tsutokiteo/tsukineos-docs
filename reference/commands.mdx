# 命令参考

> **注**：以上为 Indev-0.1.x ~ Indev-0.2.4 已暴露的命令子集，后续版本会有变动，以 `tknpkg list` 与实际 binary 为准。

## 提示

- **自研命令**：`tsukine_top`, `tknpkg`, `taskmgr`, `net`, `iwr` 是 TsukineOS 自编译的工具，源码位于 `src/tools/`。
- **BusyBox 命令**：大部分基础命令由 BusyBox 提供，静态编译，无外部依赖。
- **Dash 命令**：Shell 内置命令（如 `cd`, `echo`, `pwd`）由 Dash 提供，轻量快速。
- **版本差异**：不同版本（Indev-0.1.x vs Indev-0.2.4）命令可能有增减，请以 `tknpkg list` 和实际 binary 为准。
- **扩展**：可通过 `tknpkg install <pkg>` 安装更多工具（如 `vim`, `git`, `python3` 等）。

## 示例：常用命令组合

```bash
# 查看系统资源
tsukine_top

# 更新包索引并安装 vim
tknpkg update
tknpkg install vim

# 扫描并连接 Wi-Fi
net scan
net connect MyWiFi

# 下载文件
iwr https://example.com/file.txt

# 查看网络接口
ifconfig
ip addr

# 查看进程
ps
top

# 重启系统
reboot
```
