# 命令参考 — Tsukine OS 命令速查

## 系统核心命令

| 命令 | 功能 | 示例 |
|------|------|------|
| taskmgr / tsukine_top | 任务管理器，显示进程列表 | taskmgr -u （仅用户进程）taskmgr -c （仅内核进程） |
| net / tsukine_net | 网络配置守护进程 | net & （后台运行） |
| netui / tsukine_net_ui | 网络流量监控 | netui |
| ping / tsukine_ping | ICMP 连通性测试 *(注：自研实现)* | ping -c 4 8.8.8.8 |
| iwr / tsukine_iwr | HTTP 下载工具 | iwr http://example.com/file -o out.txt |
| reboot / tsukine_reboot | 重启系统 | reboot |
| shutdown / tsukine_shutdown | 关机 | shutdown |

---

## 包管理命令

| 命令 | 功能 | 示例 |
|------|------|------|
| tknpkg install <包名.tkn> | 安装 .tkn 包 | tknpkg install hello-1.0.0.tkn |
| tknpkg remove <包名> | 卸载已安装的包 | tknpkg remove hello |
| tknpkg list | 列出已安装的包 | tknpkg list |
| tknpkkj build <目录> | 从源码目录生成 .tkn 包 | tknpkkj build mypkg/ |

## 文本编辑与文件查看

*以上命令由 BusyBox 提供，用法与标准 Linux 一致。*

| 命令 | 功能 | 示例 |
|------|------|------|
| nano | 文本编辑器 | nano /etc/profile |
| cat | 查看文件内容 | cat /etc/hostname |
| ls | 列出目录内容 | ls -l /usr/bin/ |
| cp | 复制文件或目录 | cp file1 file2 |
| mv | 移动或重命名文件 | mv old new |
| rm | 删除文件 | rm /tmp/test.txt |
| mkdir | 创建目录 | mkdir /home/user |
| chmod | 修改文件权限 | chmod +x /usr/bin/script |

## 配置文件路径

| 文件 | 用途 |
|------|------|
| /etc/profile | 环境变量和提示符设置 |
| /etc/passwd | 用户账户信息 |

| /etc/group | 用户组信息 |

| /etc/network/interfaces | 网络配置（静态 IP / DHCP） |
| /var/log/tsukine_net.log | 网络服务日志 |
