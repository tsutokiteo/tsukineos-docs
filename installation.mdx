# 安装（镜像启动）

TsukineOS 当前**没有图形安装器**，提供的是成品镜像：x86_64 使用 `.iso`，ARM64 使用 `.img`。

## 获取镜像

前往 GitHub Releases 下载最新版（当前 **Infdev-0.2.4**）：

https://github.com/tsutokiteo/TsukineOS/releases

| 架构 | 文件 | 用途 |
|------|------|------|
| x86_64 | `tsukineos-infdev0.2.4-x86_64.iso` | 物理机 / QEMU / Ventoy |
| ARM64 | `tsukineos-infdev0.2.4-arm64.img` | 树莓派等 ARM 设备（SD 卡烧录） |

## x86_64：三种启动方式

**1. QEMU（推荐先试，最稳）**
```bash
qemu-system-x86_64 -m 2048 \
  -cdrom tsukineos-infdev0.2.4-x86_64.iso -boot d
```

**2. Ventoy U 盘**
将 ISO 放入 Ventoy 分区，开机从 Ventoy 菜单选择该 ISO。

**3. 裸机直写（谨慎）**
```bash
sudo dd if=tsukineos-infdev0.2.4-x86_64.iso of=/dev/sdX bs=4M status=progress
```
> `sdX` 为目标盘符，写错会清空整盘数据。

## ARM64：烧录 SD 卡

```bash
xzcat tsukineos-infdev0.2.4-arm64.img.xz | sudo dd of=/dev/mmcblk0 bs=4M status=progress
```
烧写完成后插入树莓派类设备开机即可。

## 系统要求

| 项目 | 最低 | 建议 |
|------|------|------|
| CPU | x86_64 或 ARM64 | x86_64 |
| 内存 | 512 MB | 2 GB |
| 存储 | 足够存放镜像 | 16 GB 以上 |
| 其他 | — | 低延迟音频设备（GUI 就绪后使用） |
```
