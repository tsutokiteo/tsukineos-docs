# 安装（镜像启动）

TsukineOS 目前**没有图形安装器**。你拿到的是成品镜像：x86_64 用 `.iso`，ARM64 用 `.img`。

## 获取镜像

前往 GitHub Releases：

https://github.com/tsutokiteo/TsukineOS/releases

| 架构 | 文件 | 用途 |
|------|------|------|
| x86_64 | `tsukineos-indev0.1.1-x86_64.iso` | 物理机 / QEMU / Ventoy |
| ARM64 | `tsukineos-indev0.1.1-arm64.img` | 树莓派类设备烧录到 SD 卡 |

## x86_64：三种跑法

**1. 虚拟机（最省事，推荐先试）**
```bash
qemu-system-x86_64 -m 2048 -cdrom tsukineos-indev0.1.1-x86_64.iso -boot d
```

**2. Ventoy U 盘**
把 ISO 扔进 Ventoy 分区，开机选它。

**3. 裸机烧录（谨慎）**
```bash
sudo dd if=tsukineos-indev0.1.1-x86_64.iso of=/dev/sdX bs=4M status=progress
```
> `/dev/sdX` 别写错，会清空整盘。

## ARM64：烧 SD 卡

```bash
xzcat tsukineos-indev0.1.1-arm64.img.xz | sudo dd of=/dev/mmcblk0 bs=4M status=progress
```
插树莓派类设备开机。

<Warning>
  当前 x86_64 实机启动在部分机型上仍需排查 UEFI/ACPI，虚拟机是最稳的验证路径。
