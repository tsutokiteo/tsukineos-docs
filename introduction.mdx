# TsukineOS

TsukineOS 是一个基于 **Linux 6.6 LTS** 的轻量级操作系统，目标是为音乐创作者提供一个**轻量、可控、开箱即用**的 Linux 环境。当前处于 **Alpha / Infdev（底层重构）阶段**，尚无图形界面，启动后进入命令行；底层、包管理与网络栈已可用。

<Note>
  当前已发布 **Infdev-0.2.4**（ARM64 移植完成，x86_64 实机适配持续推进）。系统仍属开发期，建议在闲置机或虚拟机中体验，勿用于生产环境。
</Note>

## 核心定位

- **轻量**：最小化用户空间（BusyBox + dash），低资源占用
- **可控**：自研任务 / 网络 / 包管理工具链，行为透明
- **开箱即用**：镜像即成品系统，写入即可启动

## 当前能力

- x86_64 与 ARM64 **双架构镜像**（ISO / IMG）
- 持久化存储、包管理工具、网络层已重构完成
- 自研工具：`taskmgr`（任务管理）、`net`（网络配置）、`ping`（ICMP）、`iwr`（HTTP 下载）、`tknpkg`（包管理）、`tknpkkj`（打包）
- ARM64 已在 Redmi Pad SE 上完成构建，可适配树莓派等 ARM 设备

## 当前限制

- 无图形界面（GUI 计划在 Alpha-0.3.0）
- x86_64 实体机 UEFI/BIOS 引导与驱动加载仍在适配
